# 图渡

让中文互联网的表情包跟着你一起出海。

图渡是一款面向 macOS 的本地桌面应用，可以从微信或本机导入表情，整理成自己的素材库，再发送到 WhatsApp 或导出到本地文件夹。

> Helping Chinese memes travel abroad — from WeChat and local folders to WhatsApp.

## 你可以用它做什么

- 从微信 4.x 导入收藏、自定义表情和已下载的官方表情专辑。
- 从微信 3.x 导入旧版收藏表情（Legacy Beta）。
- 从本机选择图片或整个文件夹，统一整理到素材库。
- 预览、搜索、筛选、排序和批量选择静态或动态表情。
- 自动准备符合 WhatsApp 要求的 sticker pack，并在发送前逐包检查。
- 将选中的表情导出到本地文件夹。
- 按来源和微信账号区分素材，同时对重复内容进行合并整理。

## 使用流程

1. 选择微信、本机文件或已有素材库作为来源。
2. 选择 WhatsApp 或本地文件夹作为目的地。
3. 搜索、筛选并挑选这次需要迁移的表情。
4. 检查转换和分包结果，然后开始传输。

微信导入可能需要你暂时退出当前微信，并在临时打开的微信中完成一次确认或扫码。操作结束后，图渡会关闭并清理临时副本，再重新打开原来的微信。

## 隐私与安全

- 表情整理、转换和导出都在本机完成，图渡不提供也不依赖项目方服务器。
- 应用只读取导入所需的数据，不会修改微信原始数据库或源图片。
- 微信数据库访问凭证和 WhatsApp 登录凭证保存在本机，并使用 macOS 提供的安全存储能力保护。
- 只有在你主动选择并确认后，应用才会读取或发送相应内容。
- 你可以在应用内退出 WhatsApp，并清除本地保存的登录凭证。

建议在首次批量迁移前备份重要表情，并只处理属于你自己的账号和数据。

## 系统要求

- macOS 13 Ventura 或更高版本。
- 主要支持 Apple Silicon Mac。
- Intel Mac 版本目前标记为 Beta。
- 普通用户不需要另外安装 Node.js 或其他开发工具。

正式安装包发布后会通过本项目的 GitHub Releases 提供。请只从项目官方发布页面下载安装，不要运行来源不明的安装包或要求关闭系统安全保护的脚本。

当前版本仍处于公开发布准备阶段。

## 支持范围与说明

- 当前主要目标平台是 WhatsApp；后续可能增加更多聊天平台。
- 微信或 WhatsApp 更新后，部分导入和发送能力可能需要跟随适配。
- 图渡是非官方工具，与腾讯、微信、Meta 或 WhatsApp 没有关联，也未获得这些公司的认可或授权。
- 使用本工具时，请遵守所在地法律以及相关平台条款。
